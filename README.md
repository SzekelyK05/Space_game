# Space_game

A simple 2D game playable directly in your IDE's terminal. The player controls a ship in 4 directions(up, down, left, right) and shoots incoming enemies. If an enemy reaches the left wall, the game ends. With every enemy shot, the score increases Only 3 shots can be fired at a time.

## Features
Built with standard C++20 features
Infinite game with random enemy spawns
Smooth rendering using Windows API
Difficulty increases with the score

## Controls
W / A / S / D - moving
SPACE -shooting
X - exit

## Build and Run instructions
Requires Windows environment and C++ compiler (like MSVC via Visual Studio or MinGW)
Simply executing the program with your IDE's Build and Run will start the game.
